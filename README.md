# 噜噜桌宠 LuluPet

> 给两个人用的 macOS 桌面宠物。你的桌面住着你的噜噜，TA 的桌面住着 TA 的噜妹；
> 想 TA 的时候，发颗爱心、说句话，或者让自己的小水豚**跑到 TA 的桌面上去串门**。

## 快速开始（3 步）

> 适合"懂一点代码"的你：会打开"终端"、复制粘贴命令就够了。完全不写代码？看 [给不写代码的人](#给不写代码的人)。

**① 克隆并运行 `./scripts/setup.sh`**

```bash
git clone https://github.com/richardzhuang0412/LuluPet.git LuluPet && cd LuluPet
./scripts/setup.sh
```

它会检查你的 Mac（macOS 14+、Command Line Tools、Swift 6+），然后构建出 `dist/LuluPet.app` 和 `dist/LuluPet.zip`（第一次大约 1–3 分钟）。
缺 Command Line Tools 的话它会告诉你运行 `xcode-select --install`。不需要完整的 Xcode，也不需要 Python。

把 `LuluPet` 拖进"应用程序"。第一次打开会被系统拦住（App 没有签名，正常现象）：
**系统设置 → 隐私与安全性 → 往下滚 → 仍要打开**（macOS 14 是右键 → 打开）。
把 `dist/LuluPet.zip` 隔空投送或微信发给对方，对方也这样装一次。

**② 按 [docs/firebase-setup.md](docs/firebase-setup.md) 建你们自己的 Firebase（每对情侣自己的）**

LuluPet 没有公共服务器：每对情侣用自己的免费 Firebase 实时数据库，数据只有你们俩能看到。
只需要**一个人**做，大约 10 分钟，最后得到一个数据库地址，长这样：`https://你的项目-default-rtdb.firebaseio.com`。

**③ 两个人配对**

第一次打开 App 会弹出设置窗口：
1. 一个人选 **我是噜噜**，另一个人选 **我是噜妹**。
2. **只让一个人**点 **生成**，得到 24 位配对码，复制发给对方；另一个人粘贴进去。
3. 两个人都填**同一个**数据库地址（`https://你的项目-default-rtdb.firebaseio.com`），点 **保存**。
4. 菜单栏的 🍊 里显示"对方在线"，就是连上了。双击桌宠，发一颗 ❤️ 试试！

> 配对码相当于你们俩的钥匙，不要发到公开的地方。

> 🇨🇳 **在中国大陆**：Firebase 是 Google 的服务，需要两台电脑的网络都能访问 Firebase（`firebaseio.com`）。
> 如果不方便，可以把后端换成国内的服务：所有网络请求都集中在
> [`Sources/LuluSync/FirebaseClient.swift`](Sources/LuluSync/FirebaseClient.swift) 这一个文件里，改它就行。

### 全部功能

| 功能 | 说明 |
|---|---|
| 桌面常驻 | 透明、置顶、可以拖到任何位置，所有桌面空间都能看到 |
| 自己的角色 | 噜噜用户的桌面上是噜噜，噜妹用户的桌面上是噜妹 |
| 随机小动作 | 空闲时每隔 45–120 秒随机眨眼、挥手、转圈、跳舞… |
| 打瞌睡 | 15 分钟没碰它就闭眼打瞌睡（v0.8：一张闭眼的静止画面 + 慢慢飘的 Zzz，不再一直动），一碰就醒 |
| 安静模式（省电） | 2 分钟没碰它、也没人来串门时，它就停下来摆一个好看的安静姿势（每套造型都挑了一帧：睁眼、正面、乖乖站着），不再播放动画、也不做小动作；鼠标移到它身上、点它、来消息时立刻又动起来 |
| 省电 | 动画交给系统的 Core Animation 画（不再每帧唤醒 App）；锁屏、显示器睡眠、桌宠被完全挡住时停止一切动画；用电池或低电量模式时，在线心跳 / 查询对方改成 30 秒一次、鼠标悬停检测 4 次/秒、全屏检测 8 秒一次，插上电源自动恢复 |
| 勿扰模式 | 🍊 菜单 →「勿扰模式」：选个心情（😤 生气中 / 💼 忙碌中 / 😴 休息中 / 🤐 不说原因），开 30 分钟 / 1 小时 / 今天之内 / 直到我关掉。开着的时候你的角色安安静静站着，头上挂个小牌子；TA 发来的所有东西（爱心、串门、文字、表情）都先攒着，不跑来、不冒气泡、不出声，菜单栏显示 🍊N。重启 App 也还开着，到点自动结束 |
| 诚意清单 | 勿扰结束时 TA 的角色跑来送一张卡片：「你勿扰的时候，TA 来找过你 N 次～」，列出 ❤️ 爱心 ×3 / 🏃 来找你 ×2 / 💬 4 条消息 / 🤗 抱抱 ×1…；点「看看」打开记录，「记录」里还会标出这段勿扰（😤 勿扰中 14:05–15:10） |
| TA 开了勿扰 | 菜单栏显示「TA 勿扰中（😤 生气中）」；这时发任何东西，你的角色照样跑出去、等一会儿再回来说「TA 开了勿扰（😤 生气中），先放在 TA 那儿啦」——爱心和「去找TA」也都会存着，TA 关掉勿扰就能在诚意清单里看到 |
| 换回上一个 / 选择造型 | 「换回上一个」回到之前穿的造型（可以连续往回退，最多记 10 套）；「选择造型 ▸」直接挑一套（节日限定的过了季节不能选，除非正固定着它）。固定了造型时，换了之后固定的也跟着换 |
| 换装 | 噜噜 11 套、噜妹 9 套造型（见下面的造型表），每 30 分钟自动换一套（随机），也可以「换个造型」或「固定这套造型」 |
| 节日限定 | 醒狮新年只在春节前后 15 天出现，圣诞树只在 12 月出现；当季时一打开就穿它，自动换装时也更常抽到（固定了的造型照样保留） |
| 串门穿同一套 | 对方现在穿什么，TA 的角色来串门时就穿什么（对方的版本更新、这边没有那套时，穿默认造型） |
| 传话 | 双击角色打开面板：❤️ 发送爱心、文字（≤500 字）、24 个快捷表情 |
| 串门 | 对方发来消息时，TA 的角色从屏幕边上跑进来，两只一起随机互动（抱抱、亲亲、贴贴、跳舞…），然后冒气泡 |
| 去找 TA | 自己的角色跑出屏幕、闯进对方桌面抱一下；对方不在线时会跑回来说"TA 不在哦" |
| 送信串门 | 发任何东西（❤️、文字、表情、去找 TA）都是自己的角色亲自跑去送：跑出屏幕，在对方桌面见面，过一会儿跑回来说"送到啦 ❤️"；TA 的角色正在你这儿做客时就地见面；对方不在线时跑到边上就回来（文字和表情照样留给 TA） |
| 在 TA 那边的时候 | 自己的角色出门时 TA 发来的消息先攒着，角色回家后一起给你看 |
| 同时出门 | 两个人同时发，先发的那只跑去对方家见面（同一毫秒噜噜先），然后两只一起走回先发那边再见一面，最后后发的那只回家，把对方留下的话带给你 |
| 收到 ❤️ | TA 的文字 / 表情气泡右下角有个「收到 ❤️」小按钮，点一下（或点气泡）就是收到了，接着看下一条；都收到后 TA 挥挥手回家 |
| 不会一直等 | TA 的角色最多在你这儿待 45 秒（聊着聊着又来新消息就重新算），到点自己挥手回家；还没来得及看的话不会丢，变成"TA 留下的话"留在你的角色头上，点「收到 ❤️」再一条条看 |
| 拖到一起 | 串门时把两只拖到一起，会合体播放一段互动 |
| 离线消息 | 对方离线时发的消息存在云端，上线后补收，一条不丢 |
| 快捷键 | ⌃⌥L 显示或隐藏，⌃⌥M 打开传话面板，⌃⌥Q 退出（都可以在设置里改） |
| 大小 | 鼠标移到角色上，右下角出现一个小圆点，按住斜着拖就能等比例放大缩小（0.6×–1.6×，脚底不动）；菜单"大小"里有 小 / 标准 / 大 和"恢复默认大小"。来串门的 TA、合体动画、爱心和 Zzz 都跟着一起变 |
| 隐藏 | 隐藏 5 分钟 / 30 分钟 / 1 小时 / 一直隐藏；全屏时自动隐藏 |
| 你不在的时候 | 隐藏期间来的消息会攒起来，重新出现时 TA 的角色跑来送一张小结卡片 |
| 消息记录 | 传话面板里的"记录"标签页，按天分组，可以一直往回翻 |
| 声音 | 跑来串门、抱抱、亲亲、爱心、气泡、生气、开心、打瞌睡、"你不在的时候"卡片都有小音效，每次随机一个（哭哭、贴贴、离开、去找 TA、单击暂时没有声音）；默认开、音量"小"，隐藏时完全不出声；可选背景音乐（默认关，只放一首不循环） |
| 历史不丢 | 云端和本地各存一份，升级、重装、换电脑都能自动补齐 |

## 给不写代码的人

不想装开发工具？可以直接下载打包好的 App：

1. 到 GitHub Releases 下载 `LuluPet.zip`：https://github.com/richardzhuang0412/LuluPet/releases/latest
   （打包好的版本是在 Apple 芯片（M1/M2/…）的 Mac 上构建的；Intel Mac 请按快速开始自己构建。）
2. 双击解压，把 **LuluPet** 拖进"应用程序"。
3. 第一次打开会被拦住（App 没有签名和公证，作者没有付费开发者账号）：
   - macOS 15 及以后：先双击一次 → 点 **完成** → 打开 **系统设置 → 隐私与安全性**，往下滚，
     找到"已阻止 LuluPet"，点 **仍要打开**，输入开机密码确认。
   - macOS 14：在"应用程序"里右键点 LuluPet → **打开** → 再点 **打开**。
   - 如果提示"已损坏，无法打开"，在"终端"里运行 `xattr -dr com.apple.quarantine /Applications/LuluPet.app` 再打开。
4. 然后照 [快速开始](#快速开始3-步) 的 ② ③ 步：建你们自己的 Firebase，两个人配对。

> 只从你信任的地方下载（本仓库的 Releases 页面）；不放心的话就按快速开始自己构建，代码都在这里。

## 使用说明

| 操作 | 效果 |
|---|---|
| 单击角色 | 它自己动一下（不发送任何东西） |
| 双击角色 / ⌃⌥M | 打开传话面板（传话 / 记录两个标签页） |
| 拖动角色 | 移到任意位置，下次打开还在那里 |
| 右键角色 / 点 🍊 | 菜单：状态、去找TA、隐藏、勿扰模式、声音、大小、换个造型、换回上一个、选择造型、固定这套造型、设置、退出 |
| 🍊 菜单 → 勿扰模式 | 先在「心情」里选一个（默认 🤐 不说原因），再在「开启」里选多久；开着时最上面是「关闭勿扰（15:10 结束）」或「关闭勿扰（手动关闭）」。开着时自己照样能发消息 |
| 拖角色右下角的小圆点 | 等比例放大 / 缩小（往右上变大，往左下变小；鼠标移到角色上才出现） |
| 🍊 菜单 → 大小 | 小 / 标准 / 大，恢复默认大小（拖出来的大小不在这三个里时，菜单上显示百分比） |
| 🍊 菜单 → 声音 | 开 / 关，音量 小 / 中 / 大，背景音乐；设置窗口里也有开关、音量滑块和「试听」 |
| ⌃⌥L | 显示或隐藏 |
| ⌃⌥Q | 退出噜噜桌宠（和 🍊 → 退出 一样；⌘Q 故意不用，免得关面板时误退） |

**菜单栏 🍊 的状态**：对方在线、对方离线、TA 勿扰中（😤 生气中）、连接中…、未连接（会附上原因）；自己开着勿扰时下面多一行「🔕 我勿扰中（…）」。出问题时图标变成 `🍊!`，隐藏或勿扰期间有新消息时显示条数，比如 `🍊3`。

**省电是怎么做的**（v0.8）：闲着时它每 2 分钟没人理就停成一张静止的画，15 分钟后闭眼打瞌睡（也是静止的）；锁屏、息屏、被挡住时完全不画；用电池时把网络心跳和检测都放慢。实测（一个测试实例，0.6× 大小，60 秒平均）：
CPU 0.38% → 0.15%，能耗值（活动监视器的「能耗影响」）0.50 → 0.26；电池模式下 0.03% / 0.10。

**常见问题**：见 [docs/firebase-setup.md 的「常见问题」](docs/firebase-setup.md)。

## 给开发者：从源码构建

**环境**：macOS 14+，只需要 Xcode Command Line Tools（`xcode-select --install`，Swift 6+），不需要完整的 Xcode。
生成好的 `Resources/`（抠好图的动画帧、表情）已经提交在仓库里，所以平时构建**不需要 Python**。
只有改了 `assets/` 里的素材、要重新生成 `Resources/` 时，才需要 Python 3 和 Pillow（`python3 -m pip install --user pillow`）。

```bash
./scripts/setup.sh                        # 检查环境 + 构建（新手推荐）
./scripts/build_app.sh                    # 只构建：swift build -c release → 打包、ad-hoc 签名 → dist/LuluPet.app 和 dist/LuluPet.zip
./scripts/build_app.sh --rebuild-assets   # 先从 assets/ 重新生成 Resources/（需要 Pillow；也可以设 LULUPET_REBUILD_ASSETS=1）
```

开发时直接运行，不用打包：

```bash
python3 tools/build_sprites.py                      # 只有素材清单或 GIF 变了才需要重跑
swift build
LULU_RESOURCES=$PWD/Resources .build/debug/LuluPet --profile devA
```

- `--profile NAME`：每个 profile 有独立的配置、位置和本地历史，可以在一台 Mac 上同时开两只来测试。
- `--demo`：自动填一个假的配置，不用联网也能看界面。
- 其他调试参数（`--demo-visit`、`--snapshot DIR` 等）见 `docs/superpowers/specs/2026-09-28-visits-design.md`。

**本地假数据库**（不用 Firebase 就能测试收发消息）：

```bash
python3 tools/fake_firebase.py               # 在 127.0.0.1:8765 模拟 Firebase REST 接口和实时推送
# 在设置里把数据库地址填成 http://127.0.0.1:8765（只有本机地址允许用 http）
```

版本号在 `VERSION` 文件里；构建号自动取 git 提交次数。

```
                   素材目录、串门规则、随机反应、小结、快捷键…
  LuluSync/        Firebase REST + 实时推送（SSE）：发送队列、断线重连、心跳、离线补齐
  LuluPet/         macOS 界面（AppKit + SwiftUI）：桌宠窗口、动画播放、气泡、
                   传话和记录面板、串门控制、菜单栏、设置、全屏检测
  LuluCoreTests/   测试（本机没有 Xcode，所以写成可执行程序：swift run LuluCoreTests）
assets/
  sprites.json     角色 → 造型 → 动作（idle/react/happy/run/wave/stay/fidgets/doze）+ label / season / reactionClips
  couples.json     情侣互动动画（抱抱、亲亲、跳舞…）

  sounds.json      事件 → 音效文件（每次随机一个；没写的事件就没有声音）

```

**数据流**：`/pairs/{配对码}/messages/{id}` 里存 `{from, kind, text?, stickerId?, ts, v, outfit?}`；`/pairs/{配对码}/presence/{role}` 存 `{lastSeen}`。收消息用 Firebase REST 实时推送（`orderBy="ts"&startAt=…`），每 60 秒上报一次在线状态，本地另存一份到 `~/Library/Application Support/LuluPet/<profile>/history.jsonl`。

## 素材管线

1. 把源 GIF 放进 `assets/gifs/`，来源写进 `assets/gifs/SOURCES.txt`。
2. 在 `assets/*.json` 里引用它，可以设置 `speed`、`scale`、`frames`、`facing`。
3. 运行 `python3 tools/build_sprites.py`（或 `./scripts/build_app.sh --rebuild-assets`，需要 Pillow）：
   - 用 `tools/cutout` 调 macOS Vision 逐帧抠出主体；
   - 按角色身高统一缩放；
   - 存成 WebP；
   - 同一段动画按内容去重，只存一份到 `Resources/Clips/<hash>/`。
4. 把重新生成的 `Resources/` 一起提交（别人 clone 下来就不用再跑 Python）。
5. 音效：把文件放进 `assets/sounds/`，在 `assets/sounds.json` 里写 `{"事件": "文件.m4a"}` 或 `{"事件": ["a.m4a", "b.m4a"]}`
   （事件：arrive leave poke hug kiss nuzzle bubble angry cry happy doze awaySummary goVisit goBack notHome click，
   可选 bgm），然后运行 `python3 tools/build_sounds.py`（只用 Python 自带库，`build_sprites.py` 最后也会跑它），
   结果在 `Resources/Sounds/`。找不到的文件会打印警告并跳过。`reactions.json` 里某个表情可以加 `"sound": "事件名"` 换掉见面时的音效。
6. 用 `python3 tools/compare.py out.gif "标签:build/cut/<name>" …` 做对比预览，用 `tools/scale_check.py` 检查大小是否一致。

## 升级与兼容（必读）

**用户的聊天历史在任何版本升级后都必须完整保留。** 改代码之前请先读 [docs/upgrade-compat.md](docs/upgrade-compat.md)，要点：

- 永远不能改：bundle id `com.lulupet.app`、已有的 UserDefaults 键、Application Support 路径、Firebase 路径、消息字段名、配对码格式。
- 只能新增，不能改名或删除。旧版本 app 必须能容忍新数据：遇到不认识的消息类型，显示"请升级查看"，不能丢弃。
- 数据迁移只能增加数据，不能删除任何历史。
- 发版前的必测项：在装有旧版本、已有历史记录的 profile 上原地升级，核对历史条数和位置都没变。

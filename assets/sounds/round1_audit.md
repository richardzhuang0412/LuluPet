# 第一轮素材审计（人声分离后）

方法：对 `assets/sounds/*.m4a` 每个文件整段跑 demucs htdemucs（two-stems）拆成人声/伴奏，量“伴奏低于人声”的 dB 差，
再用 faster-whisper medium（中文，中性提示词）转写人声轨。
判定：人声轨 < -45 dBFS → 按来源判“clean SFX”（音效库）或“mostly music”；差值 ≥25 dB → “clean voice”；6–25 dB 或 ±6 dB 内 → “voice + music”；伴奏更响 → “mostly music”。
注意：demucs 会把非人声的音效也归到“伴奏”，所以“mostly music”和“clean SFX”只能靠来源标题区分；whisper 在接近无声或非语言声音上会幻觉出“请不吝点赞订阅…”“词曲 李宗盛”之类的话，已标注。没人真的听过。

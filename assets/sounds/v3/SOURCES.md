# 第三轮声音素材 · 贴贴 / 蹭蹭（nuzzle）新候选

个人非商用。第二轮的 nuzzle_01（“投降啦！别蹭啦！”）被否：是一句带推开意思的话。这轮只找**短、甜、非语言**的声音：满足的“嗯”、轻笑、闪光/摩擦/泡泡类卡通音效。

方法：B 站公开视频（未登录；用自己浏览器标签页调 view/playurl 接口拿音频地址，再在本地下载音频流）。噜噜类视频用 demucs htdemucs two-stems 分离，**输出的是人声轨**；8号披萨 音效视频是单个音效 + 数字静音，没有做分离，用的是原混音。
每段都是单声道 44.1 kHz AAC，响度约 -18 LUFS（峰值约 -1 dBFS），首尾 10 ms 淡入淡出。转写用 faster-whisper medium（中文，无提示词），对成品文件再跑一遍复核。

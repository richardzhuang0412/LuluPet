# 噜噜桌宠 · Firebase 设置和安装说明

两台 Mac 上的噜噜和噜妹要互相戳一戳、发消息，需要一个"中转站"。我们用 Google 的免费服务
**Firebase Realtime Database（实时数据库）**。只需要设置一次，大约 10 分钟。

> 只需要**一个人**（比如老公）做第 1～3 部分，然后把"数据库网址"发给对方即可。

---

## 第 1 部分：创建 Firebase 项目

1. 用浏览器打开 <https://console.firebase.google.com>，用你的 Google 账号登录。
2. 点 **创建项目**（英文界面是 **Create a project** / **Get started with a Firebase project**）。
3. 项目名称随便填，比如 `lulupet`，点继续。
   - 如果提示接受条款，勾选后继续。
   - 如果问要不要开启 **Gemini in Firebase** 之类的 AI 助手，可以关掉，不影响。
4. 问要不要启用 **Google Analytics（谷歌分析）** 时，**关掉**它（用不上），然后点 **创建项目**。
5. 等转圈结束，点 **继续**，进入项目主页。

## 第 2 部分：创建实时数据库

1. 在左侧菜单找到 **Databases & Storage（数据库和存储）** → **Realtime Database**。
   - 旧版界面里它在 **Build（构建）** → **Realtime Database**，两种都一样。
   - 找不到的话，左上角搜索框里搜 "Realtime Database"。
   - 注意：不要选 **Firestore Database**，那是另一个产品。
2. 点 **创建数据库（Create database）**。
3. **数据库位置**选 **United States (us-central1)**，点下一步。
4. 安全规则选 **以锁定模式启动（Start in locked mode）**，点 **启用（Enable）**。
   - 放心，下一步我们会换成自己的规则。

## 第 3 部分：粘贴安全规则

1. 数据库页面顶部有几个标签：**数据（Data）/ 规则（Rules）/ 备份 / 用量**。点 **规则（Rules）**。
2. 把编辑框里原有的内容**全部删掉**，粘贴下面这段（完整复制，包括最外层的大括号）：

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "pairs": {
      "$code": {
        ".read": "$code.length >= 24",
        ".write": "$code.length >= 24",
        "messages": {
          ".indexOn": ["ts"],
          "$id": {
            ".validate": "newData.hasChildren(['from','kind','ts']) && (!newData.child('text').exists() || (newData.child('text').isString() && newData.child('text').val().length <= 500))"
          }
        }
      }
    }
  }
}
```

3. 点右上角的 **发布（Publish）**。看到"规则已发布"之类的提示就成功了。
   - 如果编辑框出现红色报错，多半是复制时少了括号，重新整段复制一次。
   - 页面上可能会有一条黄色警告说"规则允许公开访问"之类的，可以忽略：
     只有知道 24 位配对码的人才能读写你们的数据。

这套规则的意思（不用看懂也行）：

- 整个数据库默认谁都不能读写；
- 只有 `pairs/<配对码>` 这一格可以读写，而且配对码至少 24 个字符（猜不到）；
- 每条消息必须带发送人、类型、时间，文字最多 500 字。

> **给以后改代码的人（升级兼容）**：规则只要求 `from` / `kind` / `ts` 三个字段，其他字段随意，
> 这是故意的——新版本可以给消息**加**字段（比如 `v`、将来的语音字段），老版本照样能写、能读。
> 消息字段**只能新增，不能改名或删除**；也不要在规则里加"禁止未知字段"之类的校验，
> 否则新老版本混用时消息会写不进去。详见 [upgrade-compat.md](upgrade-compat.md)。

## 第 4 部分：复制数据库网址

1. 点 **数据（Data）** 标签。
2. 顶部有一行网址，长得像：

   ```
   https://你的项目-default-rtdb.firebaseio.com/
   ```

3. 点旁边的复制图标，把它复制下来。**两个人要填同一个网址**，可以用微信发给对方。
   - 如果你的网址是 `...firebasedatabase.app` 结尾，说明位置没选成美国，也能用，照样填即可。

---

## 第 5 部分：安装 App

发送的一方（编译 App 的人）：用 **隔空投送（AirDrop）** 把 `dist/LuluPet.zip` 发给对方。

每台 Mac 上：

1. 双击 `LuluPet.zip` 解压，得到 **LuluPet**（显示名"噜噜桌宠"）。
2. 把它拖进 **应用程序（Applications）** 文件夹。
3. 第一次打开时 macOS 会拦一下（因为这个 App 不是从 App Store 下载的）：
   - **macOS 14**：在"应用程序"里**右键点 LuluPet → 打开**，弹窗里再点 **打开**。
   - **macOS 15 及以后**：先双击一次（会提示无法打开，点 **完成**），然后打开
     **系统设置 → 隐私与安全性**，往下滚动，找到"已阻止 LuluPet"那一行，点 **仍要打开**，
     输入开机密码确认，再点一次 **仍要打开**。
   - 只需要第一次这样，以后双击就能开。
4. 打开后 App 没有程序坞图标，只在屏幕右上角**菜单栏**出现一个 🍊，桌面上会出现小宠物。

## 第 6 部分：在 App 里配对

第一次打开会自动弹出设置窗口（以后可以点菜单栏 🍊 → **设置…** 修改）：

1. **身份**
   - 一个人选 **"我是噜噜"**（桌面上住着噜噜，噜妹发消息时会跑来串门）；
   - 另一个人选 **"我是噜妹"**（桌面上住着噜妹，噜噜发消息时会跑来串门）。
2. **配对码**
   - **只让其中一个人**点 **生成**，得到一串 24 位的配对码，点 **复制**，用微信发给对方；
   - 另一个人把收到的配对码**粘贴**进去（不要再点生成，否则两边对不上）。
3. **数据库网址**：两个人都粘贴第 4 部分复制的**同一个**网址。
4. 点 **保存**。菜单栏 🍊 里显示"在线"就说明连上了；对方也打开后，**双击**宠物打开传话面板，
   点 **"❤️ 发送爱心"** 或 **"去找TA 🏃"** 试试吧！（单击宠物只是在自己桌面上逗它玩，不会发消息。）

> 配对码就像你们俩的"钥匙"，不要发到公开的地方。

## 第 7 部分：日常使用小技巧（v0.4）

- **快捷键**（任何 App 里都能按）：
  - **⌃⌥L**（Control + Option + L）：隐藏 / 显示桌宠；
  - **⌃⌥M**（Control + Option + M）：打开传话面板（桌宠藏起来时会先出来）。
  - 想换成别的组合：🍊 → **设置…** → "快捷键和显示"，点一下框框，再按新的组合键（要带 ⌃、⌥ 或 ⌘ 其中一个），
    Esc 取消，改了马上生效；「恢复默认」改回原来的。
- **暂时藏起来**：点菜单栏 🍊（或右键桌宠）→ **隐藏** → 5 分钟 / 30 分钟 / 1 小时 / 直到我再打开。
  时间到了会自己出来；想提前叫它回来，点 🍊 → **显示噜噜**（或按 ⌃⌥L）。重新打开 App 也会出来。
- **全屏时自动隐藏**：看视频、开会共享屏幕时，全屏的那块屏幕上桌宠会自动躲起来，退出全屏再出来。
  不想要的话在设置里取消勾选"全屏时自动隐藏"。全屏时按 ⌃⌥L 也能把它叫出来。
- **藏起来的时候 TA 发了消息**：不会打扰你，菜单栏的 🍊 旁边会显示条数（比如 🍊3）。桌宠一出来，TA 的角色就会跑来，
  带一张"你不在的时候，TA来过～"的小卡片，点 **看看** 可以翻聊天记录。
- **聊天记录**：双击桌宠打开传话面板，点右上角的 **记录**，能看到你们所有的消息（按天分开，最新的在最下面）。

## 费用

免费的 **Spark 方案**就够了，不用绑信用卡。实时数据库的免费额度大约是：
存储 1 GB、每月下载 10 GB、同时在线连接 100 个。
两个人戳一戳、发消息，每月用量通常只有几 MB，远远用不完。

## 常见问题

**菜单栏显示"未连接"或"配置有误"**

1. **网址**：打开 🍊 → 设置…，确认网址以 `https://` 开头、是 Firebase 数据页顶部那一串，
   前后没有多余空格。两个人的网址必须一模一样。
2. **规则**：回到 Firebase 控制台 → Realtime Database → 规则，确认内容是上面那段，
   并且已经点了 **发布**（没发布的话仍是锁定模式，所有读写都会被拒绝）。
3. **配对码**：两个人的配对码必须完全相同，且是 24 位。
4. **网络**：确认电脑能上网；公司网络或代理/VPN 有时会拦截 `firebaseio.com`，换个网络试试。

**一边显示"在线"，另一边收不到**

多半是配对码或网址不一致，两个人都打开设置对照一下。

**对方显示"离线"**

对方的 App 没开，或者电脑睡眠了。这时发的消息会保存在数据库里，对方下次打开 App 时会收到。

**打开时提示"已损坏，无法打开"**

在"终端"里运行下面这行（去掉隔空投送带来的隔离标记），再打开一次：

```bash
xattr -dr com.apple.quarantine /Applications/LuluPet.app
```
